# Controls

Press `Insert` near an active television to capture or release Doom controls.

## Default key mappings

| Action | Default key |
|---|---|
| Capture or release controls | `Insert` |
| Move forward | Up Arrow |
| Move backward | Down Arrow |
| Turn left | Left Arrow |
| Turn right | Right Arrow |
| Attack | Right Control |
| Use / Open / Confirm | Enter |
| Run | Right Shift |
| Previous weapon | Page Up |
| Next weapon | Page Down |
| Open menu / Go back | Backspace |
| Create manual savegame | Home |
| Load latest manual savegame for the TV | End |

All key mappings can be changed in the Minecraft controls menu.

## Why Backspace is used for menu navigation

Minecraft reserves Escape for its own pause and interface behavior. DoomCraft maps Backspace to the Doom menu escape action while TV controls are captured.

## Compact keyboards

Some compact, laptop, and Mac keyboards do not provide dedicated Insert, Home, or End keys.

Recommended solution:

1. open Minecraft controls;
2. locate the DoomCraft category;
3. assign convenient unused keys;
4. check modpack conflicts before testing.

## Control focus

DoomCraft forwards controls only when:

- a supported WAD session exists;
- the player is close enough to the active TV;
- the TV is not broken;
- input focus has been captured.

Press `Insert` again before interacting normally with Minecraft.
