# DoomCraft Wiki

Welcome to the official documentation for **DoomCraft**, a Fabric mod for Minecraft Java Edition 26.2 that adds a functional retro CRT television capable of running user-provided WADs through an isolated LZDoom process.

DoomCraft does **not** include or download WAD files. Players must provide files they have the legal right to use.

## Supported native packages

- Linux x86-64
- Windows x86-64
- macOS Intel x86-64
- macOS Apple Silicon ARM64

Linux is the author-tested platform. Windows and macOS packages are compiled and validated by CI, and broader community runtime reports are welcome.
